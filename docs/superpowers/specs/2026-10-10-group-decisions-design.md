# 群聊决策记录与聊天里的约定面板设计

日期：2026-10-10
状态：已确认，进入实施

## 目标

1. 从群聊里找出“已经定下来的事”和“还没定下来的事”，作为可确认、可编辑、可标记推翻或解决的记录保存，
   每条都能回到原话。
2. 在聊天详情里集中展示这个聊天的约定，群聊再加上决策记录。

## 已确认的决策

| 决策 | 结论 |
| --- | --- |
| 决策记录形态 | 持久化条目，和承诺雷达共用抽取层 |
| 聊天面板内容 | 只汇总已有内容：约定 + 群聊决策，不抽取人物事实 |
| 扫描触发 | 只手动：在群聊的聊天详情里按顶部时间范围扫描 |

## 非目标

- 不做人物事实抽取、不做决策的同步后自动扫描、不导出 JSONL、不做跨聊天事件、不做 MCP。

## 一、抽取层

- `ai/extraction.rs`：窗口切分、扫描计划、扫描循环、宽松 JSON 解析与通用字段读取，通过 `Extractor`
  trait 调用具体抽取器（`kind`、线索词、群聊是否要求我参与、未完成条目、提示词、校验并写入）。
- `ai/commitments.rs`：约定抽取器，行为不变。
- `ai/decisions.rs`：决策抽取器。
- `memory.rs`：按 `kind` 记录已扫描区间，以及共用的标题、日期、上下文读取。

## 二、数据层（v4）

- `memory_scans(account_id, chat_id, kind, from_local_id, to_local_id, model, scanned_at)`，
  主键 `(account_id, chat_id, kind, from_local_id)`。迁移时把 `commitment_scans` 以 `kind='commitment'`
  拷入后删除旧表。
- `decisions`：`kind`（`decision` 已决定 / `question` 待定）、`title`、`owner_name`、`due_date`、`quote`、
  `speaker_name`、用户状态 `status`（`suggested`/`active`/`closed`/`dismissed`，`closed` 对决定是“已推翻”，
  对待定是“已解决”）、AI 判断 `ai_status`（`overturned`/`changed`/`resolved`）、`ai_note`、
  `followup_local_id`、来源与元数据。唯一约束 `(account_id, chat_id, source_local_id, kind)`。

## 三、决策抽取

- 线索词：定了、就这么定、决定、确定、那就、同意、没问题、通过、改成、改到、取消、推迟、先不、暂定、待定、
  再议、还没定、谁来、谁负责、负责、方案、结论、投票、截止，以及时间词。群聊不要求我参与。
- 提示词：只从本段编号消息里找“决定”（达成一致或有人拍板的结论）和“待定”（明确提出但没定下来的事项）；
  闲聊、个人看法、单纯提问不算；列出该群最近有效的决定和待定事项（最多 8 条，D1…）供判断推翻、变化或解决。
- 校验：行号在窗口内、`kind` 合法、标题非空并截断到 60 字、置信度不低于 0.3、负责人最多 20 字、日期规则同约定；
  `resolved` 只用于待定事项，`overturned`/`changed` 只用于决定。
- AI 新条目一律 `suggested`；已有条目只写 `ai_*` 与 `followup_local_id`。

## 四、隐私

- 发送内容：含决策线索的群聊片段（每段附带前 6 条消息），以及该群有效决定与待定事项的标题。
- 云端服务时扫描前确认并显示片段数与字数。

## 五、界面

- 聊天详情摘要下方新增“约定与决策”面板：
  - 约定：这个聊天的待确认和进行中约定，可扫描这个聊天、跳到“约定与待办”。
  - 决策记录（仅群聊）：待确认 / 已决定 / 待定 / 已推翻或已解决；扫描决策；确认、编辑、标记推翻或解决、忽略、查看原话。
- 约定页和面板共用 `MemoryCard` 卡片组件。

## 六、测试与验证

- Rust：v3→v4 迁移保留区间、按 kind 区分区间、决策校验、AI 不覆盖用户、增量与续扫；约定原有测试不变。
- 评估：`extraction_eval.rs` 共用样本读取；`testdata/decisions/cases.json`。本机 `qwen3:8b` 在 8 段群聊上精确率 100%（5/5），
  召回率 83%（5/6）；漏掉的一条来自无法解析的模型回复，下次扫描会重试，不是误判。
- 前端：面板在私聊与群聊下的差异、确认、标记推翻、查看原话；约定页原有测试。
