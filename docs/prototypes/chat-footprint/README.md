# Chat Footprint --- 交互原型

## 打开方式

直接在浏览器打开 `index.html`，无需 npm、后端或
AI。HTML、CSS、JavaScript 分文件存放，方便开发者检查结构与交互。

## 原型交互

-   日期起止筛选，按范围过滤虚构数据。
-   全部 / 群聊 / 私聊筛选。
-   按日期倒序展示每日集合。
-   展开 / 折叠某一天。
-   每天显示聊天数与消息总数。
-   聊天条目显示类型、名称、消息数、首末时间。
-   点击聊天后显示定位到聊天详情的模拟页面，可返回足迹列表。
-   并列展示「AI 事件回顾」入口，但不模拟 AI 生成。
-   包含空结果状态和窄屏响应式布局。

## 注意

原型数据全部虚构，不连接真实 SQLite、不读取或上传微信聊天记录、不调用
AI。点击聊天后的详情只是模拟。正式版本必须复用现有
`ChatDetail`，按所选日期过滤消息并滚动到消息时间线。

## Cursor 实现约束

1.  先浏览原型，再编码。
2.  将其作为布局、视觉层级和交互规格，不要把原型 JS 直接搬进 React。
3.  保留现有导航、主题、日期范围选择和数据集切换。
4.  不把虚构数据、模拟详情或演示控件带入生产代码。
5.  正式版本只调用本地聚合查询，不调用 AI、LLM、embedding 或网络服务。
